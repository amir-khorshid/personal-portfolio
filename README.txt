# Amir's Portfolio — Starter Scaffold

This is a **placeholder starter**. Keep your existing working `index.html`, `style.css`, and `script.js` when merging.

## Preview
Open `index.html` in your browser. The controller icon opens the Konami challenge; successful entry opens `gaming.html`.

## File layout
- `index.html`, `style.css`, `script.js`: main portfolio
- `gaming.html`, `gaming.css`, `gaming.js`: retro gaming section
- `projects/`: project listing and detail pages
- `css/projects.css`, `js/projects.js`: project styles and future logic
- `images/`: add your own photos and screenshots
- `documents/`: add your résumé as `resume.pdf`

## To merge with your existing site
1. Back up your current website folder.
2. Copy **new** files/folders from this starter into it.
3. Do **not** overwrite your existing three homepage files.
4. In your existing `script.js`, change the successful Konami unlock handler to redirect to `gaming.html`.
5. Update project links on the homepage to `projects/homelab.html`, `projects/fpga.html`, and `projects/networking.html`.
6. Update résumé links to `documents/resume.pdf` once you have a real PDF.

Note: The gaming page is discoverable by URL. The Easter egg is not authentication.
